# 🐶🐱 Dogs vs Cats Classifier

Streamlit app using a custom CNN and a fine-tuned VGG16 (~96% validation accuracy).

## Files
- `app.py` – Streamlit app
- `dogs_vs_cats.ipynb` – training notebook (Colab)
- `models/` – trained `.keras` files
- `requirements.txt`

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
